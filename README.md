# WencanHu-XJTLU.github.io

A simple tutorial-and-article website inspired by the clear, topic-first
navigation style of W3Schools. It is a static site built with plain HTML, CSS, and
JavaScript.

## Structure

```text
WencanHu-XJTLU.github.io/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── main.js
├── assets/
│   └── favicon.ico
└── README.md
```

## Features

- Responsive top navigation and tutorial sidebar
- Tutorial topic cards
- Article list layout
- Tutorial search
- Light and dark themes
- Interactive code tabs and preview
- Scroll progress indicator

## Preview locally

Open `index.html` in a browser or run:

```powershell
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Publish

This repository is intended for GitHub Pages. In the repository settings, open
**Pages**, choose **Deploy from a branch**, then select `main` and `/ (root)`.

The demo address for this repository will be:

```text
https://xianhuiqizi.github.io/WencanHu-XJTLU.github.io/
```
